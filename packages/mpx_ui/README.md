# mpx_ui

Optional media UI for mpx: a fullscreen media viewer and feed list and pager widgets.

> Skeleton: the API lands with the tickets of the mpx build order. Nothing is
> usable yet.

## Install

Not published yet. Depend on it from git:

```yaml
dependencies:
  mpx_ui:
    git:
      url: https://github.com/itsezlife/mpx.git
      path: packages/mpx_ui
```

## Usage

```dart
import 'package:mpx_ui/mpx_ui.dart';
```

## Features (planned)

- Fullscreen viewer
- Feed list and pager widgets
